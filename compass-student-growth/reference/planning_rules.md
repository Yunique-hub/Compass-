# 规划与验收规则

- 只有主方向、目的地和求职时间均确认后才生成正式计划。
- 正式周计划总时长不超过 `weekly_hours × 0.85`，最多 3 个核心任务。
- 每项任务必须写明预计时长、产出、验收标准、依赖、资源和失败备选。
- 方向未确认时只给 1—2 周可逆探索；目的地未确认时只给通用基础建议，并注明不是本地市场规划。
- 优先级必须回溯到实际快照岗位 ID 或用户上传 JD；缺少频率时使用“JD 明确要求/通用基础”，不编造比例。

## 本地练习模板

1. Java：实现集合、异常处理和输入校验示例；运行通过；提交 README 与三条复盘。
2. 服务端项目：提交可运行接口、数据设计、自动化检查和演示说明。
3. SQL：完成 15 道场景查询，整理至少 5 个错因并复做通过。
