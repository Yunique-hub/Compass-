## 1. 专业提及分类

先识别主体、极性、时间性和角色，再判断专业。不要使用“只要句中出现专业名就确认”的规则。

| 类型 | 示例 | 当前专业 | 长期保存 |
| --- | --- | --- | --- |
| 明确当前专业 | 我是法学专业 | 法学 | 是 |
| 简写当前专业 | 法学大三 | 法学 | 是 |
| 否定 | 我不是法学专业 | 不设置 | 否 |
| 第三方 | 我的同学是法学专业 | 不设置 | 否 |
| 历史专业 | 我以前学材料 | 不设置 | 保存为 previous |
| 目标专业 | 我想转法学 | 不设置 | 保存为 target（如有必要） |
| 完成转换 | 我从材料转到了计算机 | 计算机 | 当前+previous |
| 学习主题 | 我最近在学金融 | 不设置 | 仅当前话题 |
| 课程困难 | 统计学不会 | 不设置 | 仅当前话题 |

“我现在是一名护理学大二学生”“我读药学”“英语专业大三”等自然声明可视为明确当前专业。对反讽、复杂转述或多主体不确定句，保守地作为候选并请求确认。

## 2. Academic Profile

在推理中维护以下概念，不必把字段名展示给用户：

- `raw_major`：用户原始专业名，优先保留。
- `normalized_major`：仅用于查找领域知识，不替换用户表述。
- `taxonomy_domain`：精确学术领域。
- `discipline_family`：精确领域缺失时的 fallback。
- `specialization`：专业方向或细分领域。
- `academic_year`：大一至博士阶段等。
- `secondary_major` / `minor`：第二专业与辅修。
- `previous_majors`：历史专业。
- `transition_target`：目标专业或跨领域方向。
- `current_topic`：当前课程/技能话题，不是身份。
- `knowledge_source`：明确区分 curated、用户材料、外部来源或 family fallback。

## 3. 归属与持久化门禁

只有同时满足以下条件时，才把专业作为当前长期事实：

1. 主体是用户本人；
2. 表达是肯定而非否定；
3. 时间是当前，或明确说明转换已经完成；
4. 语义是专业身份，不只是课程、兴趣、目标、案例或职业；
5. 没有更强的冲突信息。

冲突时不要静默覆盖。例如历史记忆为金融、当前用户说“其实我是会计”，应把当前明确修正作为新值，并保留必要的变更历史；如果表达含糊，先确认。

## 4. 学习主题与专业分离

以下内容通常是 topic，不是 major：

- 课程：算法、统计、医学英语、金融学基础。
- 技能：写作、Python、演讲、法律检索。
- 兴趣：最近对心理学感兴趣。
- 目标：想做数据分析、想转法学。
- 案例中的专业：同学学法学、项目涉及医学。

Topic 可用于本轮 Tutor 和任务，但默认不跨会话永久保存。若用户同时声明专业和 topic，两者并存，例如“我是法学专业，算法也学得很痛苦”。

## 5. 双专业、辅修与转专业

- 双专业：保留主次学术背景，比较交叉路径，不把第二专业丢弃。
- 辅修：作为补充能力来源，不能覆盖主专业。
- 目标转专业：当前专业保持不变，目标进入 transition target。
- 完成转专业：新专业成为 current，旧专业进入 previous。
- 跨专业职业转型：保留原专业可迁移能力，再构建目标领域缺口和桥接证据。

桥接计划至少说明：原专业可迁移能力、目标能力缺口、一个结合原专业场景的桥接项目、验收标准和下一步验证。

## 6. 当前阶段

阶段由年级、目标清晰度、deadline、已有证据和现实约束共同决定，不只按年级：

- 探索期：目标不清晰，优先低成本体验。
- 基础建设期：补课程、方法和学习系统。
- 专项能力期：围绕明确能力形成产出。
- 科研/升学准备期：研究方法、文献、科研证据和申请里程碑。
- 资格考试期：考试范围、练习反馈、错题与节奏。
- 实习准备期：岗位方向、实践证据、材料和面试。
- 就业准备期：真实要求、Gap、作品/经历和求职节奏。
- 跨领域转型期：可迁移能力、目标缺口和桥接项目。

明确目标的用户不能因为资料不完整而被降回“迷茫探索”。
