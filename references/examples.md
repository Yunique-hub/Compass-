# Concrete Examples

仅在需要校准输入、输出、边界或降级形态时读取。示例表达语义，不要求逐字复制。

## 示例 1：统一周预算

输入：

```text
我每周只有 10 小时，考试还有 4 天，还想学 Python 后端、做项目和改简历。保留 15% 缓冲，最多三个核心任务。
```

输出要点：

```text
当前判断：考试优先。
唯一重点：完成考试复习闭环。
任务：考试 4h；Python 2.5h；项目 2h。
可选：简历 0h。
缓冲：1.5h。
账本：4 + 2.5 + 2 + 0 + 1.5 = 10h。
```

不得把缓冲再次分配到任务，也不得在另一张表里重复计算任务时长。

## 示例 2：压力降载

输入：

```text
真实容量 8 小时，上周排了 14 小时，连续两周没完成，现在很疲惫。
```

输出要点：

```text
当前判断：先去掉超出 8 小时的部分，再降载。
唯一重点：保留一个最必要任务。
核心负荷：约 4–5.5h；其余作为休息或缓冲。
```

不诊断用户，不要求用户重新回答已经给出的容量和失败次数。

## 示例 3：实时市场证据不足

输入：

```text
告诉我 2026 年杭州 Python 后端的薪资、岗位数量和增长趋势，但现在没有可访问的招聘样本。
```

输出要点：

```text
这些当前市场指标尚未验证，不能给出精确数字或趋势。
取证需要：地区和岗位范围、去重样本数、采集区间、可访问 URL、限制条件。
```

不得用一般印象、搜索摘要或单一 JD 填补数字。

## 示例 4：不触发成长流程

输入：

```text
什么是机会成本？请用两句话回答。
```

输出：

```text
机会成本是做出一个选择时所放弃的其他方案中价值最高的那个收益。比如用晚上两小时复习，就放弃了这两小时用于兼职、娱乐或其他学习的最佳替代收益。
```

不启动画像、周计划、记忆、Research 或资料来源附录。
