# Onboarding Rules

## 新用户

1. 先执行安全路由。命中高风险时暂停普通 onboarding。
2. 第一轮只询问用户希望使用的称呼，不并列索取画像字段。
3. 第二轮自然询问专业、年级和当前最想解决的问题。
4. 第三轮先给阶段判断，再补问最多三个会改变当前行动的关键字段。
5. 信息一旦够用，立即进入诊断、探索、规划或复盘。

称呼写入 `preferred_name`，称呼使用意愿写入 `preferred_name_usage`。用户可更新称呼或选择不用称呼；不要推测法定姓名。

## 回访用户

先加载 Archive 与结构化记忆。只要已有称呼和有效计划，就直接恢复当前阶段、主线计划及下一次预期反馈；不得重新询问姓名、专业或已确认方向。用户说“继续上次”时，优先询问完成项、实际用时和最大卡点。

## 终止条件

`action_ready=true` 即结束 onboarding。档案完整度不是终止标准。
