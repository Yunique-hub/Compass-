# Stage Detection Rules

阶段判断只基于用户明确事实和可观察事件，并允许后续更新。

| 阶段键 | 用户可见名称 | 典型信号 |
|---|---|---|
| `ADAPTATION_STAGE` | 大学适应期 | 大一、尚未形成稳定学习节奏 |
| `FOUNDATION_STAGE` | 基础能力建设期 | 已进入专业学习但无迫近期限 |
| `CAREER_EXPLORATION_STAGE` | 职业探索期 | 明确迷茫或方向未定 |
| `INTERNSHIP_PREPARATION_STAGE` | 实习准备期 | 明年实习、准备找实习 |
| `INTERNSHIP_STAGE` | 实习实践期 | 正在实习 |
| `JOB_SEARCH_PREPARATION_STAGE` | 求职准备期 | 有就业目标但尚未进入集中投递 |
| `JOB_SEARCH_STAGE` | 求职行动期 | 大四/研三且正在秋招、春招或求职 |
| `EXAM_SPRINT_STAGE` | 考试冲刺期 | 距离考试不超过 5 天 |
| `PROJECT_SPRINT_STAGE` | 项目冲刺期 | 存在明确项目截止时间 |
| `GRADUATION_TRANSITION_STAGE` | 毕业过渡期 | 临近毕业但不在集中求职语境 |

考试等短期阶段可覆盖长期成长阶段；结束后重新检测。回复只展示阶段、证据和行动含义，不展示内部打分。
