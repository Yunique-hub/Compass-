# Compass Skill 3.2.0 培训内容对齐说明

依据《大模型教育教学应用创新赛—智能体 skills 开发平台培训视频_笔记》审计当前制品。

## 已满足

- `SKILL.md`、`manifest.yaml`、`scripts/`、`references/` 分层组织。
- L1 元数据负责触发，L2 主指令保持低于 500 行，L3 资源按需读取。
- manifest 使用 kebab-case 名称、语义化版本、private scope 和简洁 description。
- 多步骤工作流、使用边界、错误降级、可追溯引用和标准库脚本已经存在。
- 复杂 Skill 使用 ZIP 包上传，平台管理面可以解析和回下载。

## 本轮补齐

- 新增显式输入、输出、不使用边界和异常处理。
- 新增四个具体输入/输出示例，包含正常、压力、证据不足和负例。
- 新增 `tests/`，包含 pytest 单元测试和 `integration_cases.json`。
- 增加 stdout 为单一 JSON、stderr 不混入调试信息的 CLI 测试。
- 将培训的三级测试金字塔落实为单元测试、集成用例和平台 E2E 证据。

## 保留差异

- 培训笔记使用 `reference/` 表述；当前 Codex 规范和平台既有包使用 `references/`。本轮保留 `references/`，避免同时存在两个近义目录造成加载歧义。
- 测试与发布报告放在包外 `docs/`；包内只保留运行所需资源和培训明确要求的 `tests/`。

## 版本策略

用户将本轮目标明确更正为 3.2.0。平台当前正式版为 3.1.0，因此本轮按次版本升级发布 3.2.0：增加培训对齐的输入输出契约、边界、示例和三级测试资产，同时保留 3.1.0 的核心工作流和校验能力。
